# whisper-speech2txt-
Whisper — это open-source модель распознавания речи от OpenAI. Она умеет:  Транскрибировать аудио на 99 языках (включая русский)  Автоматически определять язык  Переводить речь на английский  Работать с шумом, акцентами, техническими терминами  Давать таймкоды для субтитров (.srt)
